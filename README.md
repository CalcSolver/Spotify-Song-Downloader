# 🐙 OctoFlow Downloader

Fast, simple, and modern music downloader built for OctoFlow.

Search tracks, albums, and playlists from multiple music sources and quickly access music from publicly available sources.

---

> [!WARNING]
> 🐙 This octopus is not a lawyer.
>
> OctoFlow searches multiple music sources and does not host the music itself.
>
> Please respect copyright laws and the terms of service of any platforms you use.

---

## ✨ Features

- 🔍 Search music across multiple sources
- 🎵 Fast song lookup
- 📋 Playlist support
- 💿 Album support
- ⚡ Modern interface
- 🐙 OctoFlow integration
- 🎨 Album artwork retrieval
- 📝 Metadata support
- 🚀 Lightweight and fast
- 📱 Mobile friendly

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/octoflow-downloader.git
```

### Open the project

```bash
cd octoflow-downloader
```

### Run

Open:

```txt
index.html
```

Or host it using your preferred web server.
